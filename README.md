# 🌌 Acerca del proyecto

**MovieSync** es una aplicación multimedia desarrollada con Flutter enfocada en la exploración y visualización de películas y series.

El proyecto cuenta con una interfaz inspirada en plataformas de streaming modernas, ofreciendo una experiencia fluida, elegante y optimizada para múltiples tamaños de pantalla.

La aplicación utiliza la API de **The Movie Database (TMDB)** para obtener información actualizada sobre películas, series y contenido multimedia.

## 🚫 No almacena contenido multimedia

**MovieSync**:

- ❌ No almacena películas
- ❌ No distribuye contenido multimedia
- ❌ No hospeda videos
- ✅ Solo consume metadata desde TMDB
- ✅ Utiliza servicios externos para streaming

---

## 🌐 Servicios de terceros

Todo el contenido multimedia es proporcionado por servicios externos y de terceros.

El desarrollador no tiene control sobre:

- Privacidad de terceros
- Disponibilidad del contenido
- Material multimedia externo

# ⚡ Instalación

## 1️⃣ Clonar repositorio

```bash
git clone https://github.com/isairey/PlataformaPeliculasFlutter.git
```

```bash
cd PlataformaPeliculasFlutter
```

---

## 2️⃣ Configurar entorno

Crear archivo `.env`

```env
TMDB_API_KEY=your_api_key_here
```

---

## 3️⃣ Instalar dependencias

```bash
flutter pub get
```

---

## 4️⃣ Ejecutar aplicación

```bash
flutter run
```
